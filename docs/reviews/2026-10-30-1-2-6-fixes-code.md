# Review: the 1.2.6 fixes (#21)

Two fresh agents read the change at `d53bd76`.
- **The security reviewer** drove 866 path values through the library on .NET Framework 4.0, 4.6.1 and 4.8 and on net10.0. Each value was sent byte for byte as escaped, or refused before anything was sent. It also broke each fix in a clone and saw its tests fail.
- **The correctness reviewer** checked each fix against Tableau's REST API reference, and every enum against the 3.29 schema. Strict ApiCompat against nuget.org's 1.2.5 lists only appended enum members and the assembly version.

## Refuted

- **Coverage:** every request goes through the path handler, with no string path that bypasses it, uploads, downloads and both publishes included.
- **The exact check:**
  - it never refuses a legitimate value (ids with `:`, sub-delimiters, non-ASCII names);
  - no value reaches another path on any target.
- **Redirects:** off on the only handler, and the message carries no credential.
- **The time-zone test:** restores its state.
- **`UpdateTo*Schedule`'s exception:** lands in the Task.
- **No enum member moved.**
- **Public text:** describes what changes, never how to attack.
